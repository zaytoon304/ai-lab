# القاعدة الذهبية التفاعلية

## كتاب إلكتروني تفاعلي لتعليم القراءة والكتابة العربية

**إعداد وتصميم: محمد زيتون**

هذا المستودع يحتوي على مشروع **القاعدة الذهبية التفاعلية**، وهو تطبيق ويب تعليمي عربي تفاعلي للطلاب.

### الموجود في المشروع حاليا

- دروس تفاعلية للقراءة والكتابة.
- ألعاب تعليمية.
- أنشطة استماع وإملاء وبناء كلمات.
- قصص تفاعلية.
- اختبارات وتحديد مستوى.
- ملف تقدم للطالب.
- لوحة للمعلم وتحليلات للصف.
- لوحة لولي الأمر.
- خطط علاجية.
- أوراق عمل وبطاقات تعليمية واختبارات قابلة للطباعة.
- مسابقات صفية للفرق.
- دعم العمل دون إنترنت PWA.

> ملاحظة: المنصة البرمجية موجودة، لكن نقل محتوى الكتاب الأصلي كاملا ومطابقته صفحة بصفحة ما زال يحتاج إلى استكمال ومراجعة قبل اعتبار المحتوى 100% نهائيا.

## التشغيل

الصفحة الرئيسية للمشروع هي `index.html` على الفرع `main`.

عند تفعيل GitHub Pages سيعمل الموقع من عنوان Pages الخاص بالمستودع.
